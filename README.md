# AudioSplitter

Редактор аудио в одном HTML-файле: нарезка трека на фрагменты, разделение на дорожки, запись с микрофона поверх трека, сэмплы из библиотеки, обработка голоса и сведение в MP3/WAV.

Всё считается в браузере: файлы никуда не отправляются, сервер не нужен (кроме необязательного локального запуска, см. ниже). Кодировщик MP3 (`lamejs 1.2.1`, LGPL-3.0) встроен внутрь файла, поэтому приложение работает без интернета.

- Репозиторий: <https://github.com/GitIT1979/Audiosplitter>
- Версия по HTTPS (для телефона): <https://gitit1979.github.io/Audiosplitter/>

## Как запустить

**1. Просто открыть файл.** Двойной щелчок по `AudioSplitter.html`. Работает всё, кроме записи в папку библиотеки — на `file://` браузер её не разрешает.

**2. Локальный сервер (рекомендуется).** Двойной щелчок по `start-server.bat` (или `python serve.py` в папке проекта). Откроется <http://localhost:8000/AudioSplitter.html>. `localhost` считается защищённым адресом, поэтому здесь работают и доступ к папке библиотеки, и микрофон. Остановить — `Ctrl+C` в окне сервера.

**3. Телефон.** Открыть <https://gitit1979.github.io/Audiosplitter/>: без HTTPS браузер мобильного не даёт микрофон.

> Корневой адрес Pages открывает приложение с меткой времени (`AudioSplitter.html?v=…`), поэтому после обновления сайта браузер не подсовывает старую копию из кеша. Если сомневаетесь, какая версия открыта — посмотрите штамп сборки в шапке.

## Быстрый старт

1. Открыть приложение — интерфейс уже на экране, без отдельного экрана загрузки. Трек: «Открыть файл» или перетащить в любое место окна.
2. Потянуть мышью по волне — получится выделение.
3. «＋ Фрагмент из выделения» — кусок станет фрагментом; «✂ Вырезать в файл» — он ещё и сохранится файлом.
4. В карточке фрагмента поправить начало, конец, длину, фейд и громкость либо подтянуть края на волне.
5. «Сведение» → `▶ Прослушать` — услышать итог, `⤓ MP3` / `⤓ WAV` — записать его.

## Возможности

### Загрузка трека
- Отдельного стартового экрана нет: транспорт, волна и все блоки видны сразу.
- Пока трека нет, в области волны — заглушка «Перетащите трек в окно»: кнопка загрузки одна, в шапке («Открыть файл»), дубля в волне больше нет. Клик по пустой волне тоже открывает выбор файла.
- Файл можно бросить в любое место окна, а не только в волну; при перетаскивании область подсвечивается.
- Пока трека нет, кнопки воспроизведения, записи и зума выключены, а не молчат при нажатии.
- Другой трек — «Открыть файл» в шапке; если уже есть фрагменты или сэмплы, спросит подтверждение.
- **Автозапуск есть:** выбранный файл сразу играет с начала. Старый трек замолкает в момент нажатия «Открыть файл», поэтому во время выбора файла ничего не звучит. Если браузер успел «забыть» клик (файл выбирали дольше пяти секунд) — звук включится первым же кликом в любом месте, с подсказкой на экране.

### Волна и навигация
- Волна с линейкой и огибающей по каналам — широкое стерео не «схлопывается» в ноль.
- Зум ×1…×64: кнопки `−`/`+`, `Ctrl`+колесо (к курсору), двойной клик или клавиша `0` — весь трек в окне.
- Прокрутка: `Shift`+колесо или перетаскивание линейки; клик по линейке ставит курсор.
- Тянуть по волне — выделение; клик — курсор; тянуть край фрагмента — подрезка; тянуть плашку сэмпла — перемещение.

### Фрагменты
- Минимальная длина 0.05 с, поля: начало, конец, длина, фейд, громкость в дБ.
- `✂ Вырезать в файл` — создать фрагмент и сразу сохранить его файлом в выбранном формате.
- `✂ Оставить выделенное` — обрезать трек по выделению, остальное отбросить (отменяется `↶`); в подсказке пишется, что осталось и какая стала длина.
- `🗑 Удалить` — вырезать выделение из трека: остальное склеивается, фрагменты и сэмплы сдвигаются. Отменяется кнопкой `↶`.
- Правка краёв мышью, дублирование, удаление, экспорт.
- Изменения фрагмента слышны сразу, если он играет.

### Дорожки (разделение на инструменты)
Четыре суммирующихся компонента; при уровнях 100 % их сумма совпадает с исходником (с точностью до округления float):

| Дорожка | Что выделяет | Метод |
|---|---|---|
| Вокал | центр целиком (моно) | Mid-канал (L+R)/2 без фильтров |
| Инструментал | всё, кроме центра | исходник минус остальные полосы |
| Бас | ниже 140 Гц | low-pass 24 дБ/окт |
| Верх | выше 8 кГц | high-pass 24 дБ/окт |

- Уровень 0–150 % у каждой — это микшер: **любую дорожку можно вывернуть в ноль**, и она исчезает из микса целиком. «Вокал» в ноль = минусовка: убирается весь центр (вместе с центральным басом — его можно добрать ползунком «Бас»). Рядом с процентом — полоска измерителя: видно, что ползунок применился, даже без звука. Ползунки — это громкости аудио-нод (`GainNode`), поэтому звук меняется **мгновенно**, без пересборки и подвисаний.
- «Сброс» возвращает все уровни на 100 %.
- `▶` слушает только эту дорожку — через тот же граф, поэтому переключение мгновенное; если после этого двинуть любой ползунок, соло снимается и слышен микс. `⤓` сохраняет дорожку файлом.
- `▶` в шапке блока — послушать микс с текущими уровнями **без сохранения файлов**; `▶` в строке — послушать одну дорожку.
- `⤓ файл` в строке — скачать одну дорожку, `⤓ все` в шапке блока — все четыре подряд отдельными файлами. Формат берётся из списка «Формат» (MP3 192 или WAV 16 бит).
- Ряд дорожки переносится по строкам: на узкой карточке кнопки ▶ и ⤓ переезжают вниз, а не обрезаются краем.
- Живые дорожки считает потоковый процессор **тем же движком, что и экспорт**: блоками по 4096 отсчётов, с накоплением состояния фильтров. Каналы обрабатываются сами — без узлов-каналообразователей браузера, поэтому звучание одинаково во всех браузерах и совпадает с сохранённым файлом. Память не зависит от длины трека.
- Звук всегда идёт через граф дорожек: при 100 % сумма четырёх веток равна исходнику (с точностью до округления float). Ползунок в ноль убирает дорожку из микса **целиком и мгновенно** — «Вокал» в ноль даёт настоящую минусовку. Моно-файлы обрабатываются честно: канал дублируется в стерео, центр вычитается полностью, а не наполовину.

### Запись с микрофона
- `🎤` в транспорте открывает одну полосу записи: `● Начать запись`, таймер, галочка «Слышать трек», `✕` — свернуть.
- «Слышать трек» включена — играет трек с текущей позиции и пишется микрофон; выключена — пишется только микрофон (можно играть вживую под метроном-тишину).
- Запись включается после того, как трек зазвучал, — в начало не попадает пауза подготовки. Когда трек заканчивается, запись останавливается сама.
- По остановке запись становится отдельной дорожкой на волне: строка «Запись N» подсвечивается в «Звуках на треке», двигается, регулируется, сохраняется.
- Другой записи с микрофона в интерфейсе нет: `⏺ Записать исполнение` в «Сведении» — это запись микса, а не микрофона.
- Форматы: `audio/webm;codecs=opus` → `audio/webm` → `audio/mp4` → `audio/ogg;codecs=opus`.
- Запрос идёт без эхо-подавления и АРУ (они портят музыку), с откатом на обычный режим.
- Нужно разрешение; при отказе показывается сообщение. С «Слышать трек» наденьте наушники — иначе микрофон запишет и трек из динамика.

### Дорожки поверх трека (внутри карточки «Библиотека»)
Отдельной карточки нет: список дорожек живёт внизу блока «Библиотека», там же кнопка добавления.
- «＋ Добавить» — внешние дорожки файлами; запись с микрофона — одна на всё приложение, в транспорте (`🎤`). Загруженные файлы, записи и звуки библиотеки — это полноценные дорожки поверх трека.
- У каждого своя позиция на таймлайне и громкость 0–150 %: ползунок применяется к играющему звуку **мгновенно**, без остановки и пересборки.
- `🎧` солирует дорожку: один клик — слышна только она (остальные глушатся мгновенно), повторный — все возвращаются; соло действует и на сведение.
- `🔈` / `🔇` глушит дорожку на ходу и возвращает обратно; `✎` переименовывает («Вокал», «Гитара» — как удобно).
- **Комбинированное прослушивание:** `🔈`/`🔇` в транспорте глушит основной трек, не останавливая таймлайн. Дорожки-сэмплы играют дальше — прослушивайте их по отдельности (сольная `▶`, своя `🔇` у каждой) и записывайте результат: `⤓ MP3/WAV` сводит именно услышанную комбинацию (трек выключен — в файле его нет), «Записать исполнение» пишет её вживую. Отдельный экспорт фрагмента тоже уважает мьют, экспорт одной дорожки разделения — нет.
- На волне: пунктир старта, подсветка области и плашка с названием — за неё сэмпл перетаскивается.
- `▶` слушает дорожку отдельно, а поверх играющего трека — не останавливая воспроизведение.
- `✂` удаляет выделенный участок из этой дорожки, `⤓` сохраняет её файлом, `⤒` кладёт в библиотеку.

### Библиотека
- Папка `library/` на диске: `manifest.json`, звуковые файлы, `credits.txt`. **Папка — источник правды**, а не кеш браузера.
- «📂 Папка» — системный выбор папки с правом записи (Chrome/Edge): приложение читает файлы, а `💾` записывает `manifest.json` обратно.
- Папка запоминается: после перезагрузки доступ восстанавливается сам или кнопкой `🔓`.
- Файлы декодируются при первом обращении (`▶`, `＋`, перетаскивание) — подключение папки не занимает память под все звуки сразу; сортировка по длине догружает длительности в фоне.
- Где File System Access нет (Firefox, Safari, телефон) — «＋ Файлы»: ручной выбор, метаданные всё равно из манифеста.
- Поиск по названию, автору, тегу и лицензии; бейджи CC0 / CC BY / «только личное» / «своя запись».
- `▶` слушает, `＋` вставляет с позиции курсора, перетаскивание на волну ставит в точку броска.
- `✎` правит название, теги, папку и лицензию; при подключённой папке манифест перезаписывается сразу.
- `⤒` в строке сэмпла пишет его файлом в папку библиотеки и дописывает запись в манифест.
- Фильтр по папкам, чипы тегов, сортировка по имени / длине / дате / лицензии с направлением `↑`/`↓`.
- `☑` — массовые операции: папка и/или лицензия сразу для отмеченных.
- «credits» — список авторов и лицензий.
- В комплекте 118 CC0-сэмплов и 39 лупов Looperman; разложены по папкам: Ударные, Бас, Мелодика, Вокал, FX, Эмбиент, Looperman. Отчёт — `library/REPORT.md`.
- Свои файлы просто кладутся в `library/` и попадают в список. **Looperman**-лупы остаются локально: они в `.gitignore`, потому что их условия запрещают перераздачу «как есть»; в приложении у них жёлтый бейдж «только личное» и папка `Looperman`.

### Голос
Обработка записи с микрофона или любого сэмпла:

- **Шумодав** — спектральное вычитание, профиль шума по тишине между фразами.
- **Автотюн** — подтяжка к ноте: хроматика или лад (мажор/минор) с тоникой; сила 0–100 %, скорость «мгновенно / быстро / обычно / плавно».
- **Обрезка низа** 80 Гц, **компрессор** 3:1, **нормализация** до −1 дБ.
- `▶ Послушать` — без изменения файла, `Применить` — заменить дорожку (отменяется `↶`).

### Звук
- Громкость ±12 дБ, полки низа и верха ±12 дБ.
- Усиление ограничивается по пику трека: если прибавка загнала бы сигнал выше 0 dBFS, она урезается — вместо грязного клиппинга звук остаётся чистым. Правило одно для прослушивания, экспорта и фиксации; при 0 дБ усиление равно единице, без лишнего приглушения.
- Скорость 0.5–2.0 — для участка, фрагмента или целого трека. Меняет темп **вместе с тоном** (как ускорение плёнки), курсор движется синхронно.
- Настройки применяются на слух и **мгновенно**: громкость, низ, верх, скорость и уровни дорожек идут через аудио-ноды (`GainNode`, `BiquadFilterNode`, `playbackRate`) — без пересборки и без подвисаний при движении ползунков.

### Сведение
- `▶ Прослушать` — итог: трек + дорожки + запись + сэмплы + скорость и тембр. Кнопка работает как переключатель: пока играет, на ней `■ Стоп`, повторное нажатие убирает звук.
- `⤓ MP3` / `⤓ WAV` — тот же итог в файл; если выделен фрагмент, сводится только он.
- `⏺ Зафиксировать` — впечатать обработку в трек, дальше работать с готовым звуком.
- `⏺ Записать исполнение` — пишет то, что слышно, пока вы крутите ползунки и вставляете сэмплы. По остановке появляется **дубль**: послушать, сохранить или сделать треком.
- `↺ Чистый трек` — вернуть исходный файл и нейтральные настройки: не понравилось — нажали, трек снова чистый.
- Прослушивание и экспорт идут через один и тот же рендер, поэтому «слышу» и «сохранил» совпадают.

## Форматы

**Вход** — всё, что декодирует браузер: MP3, WAV, OGG/Opus, FLAC, M4A/AAC, AIFF. Ограничение платформенное: Safari не читает FLAC через `decodeAudioData`, поддержка AAC зависит от ОС. При ошибке — сообщение, а не тишина.

**Выход** — MP3 192 кбит/с (CBR) и WAV 16 бит PCM, стерео, частота исходника (неподдерживаемая MP3-частота ресемплится в 48 кГц).

## Раскладка блоков

Блоки стоят на свободном поле: у каждого свои координаты, а не место в сетке. Тяните за заголовок карточки (на телефоне — за ручку `⠿`) и ставьте блок в любое место.

- Пока тянете, видно **фиолетовый пунктир** — точка, куда встанет блок, и **серые пунктиры** — куда сдвинутся карточки, на которые он заходит. Это не догадка: призрак считается тем же правилом, что применяется при отпускании, поэтому блок встаёт ровно туда, где показано.
- По горизонтали блок встаёт в ближайшую колонку, по вертикали — там, где вы его отпустили (шаг 4 px). Так блоки никогда не накладываются друг на друга.
- Перестановка анимируется: карточки уезжают на новое место за 300 мс.
- Задетые карточки сдвигаются вниз, освобождая место. Если карточка выросла (добавили сэмпл, раскрылся список), соседи разъезжаются сами.
- Поле растёт вниз сколько нужно — блок можно поставить в самый низ.

Панель над полем:

| Элемент | Что делает |
|---|---|
| `Поле − 2 +` | сколько колонок в поле: 1–4, насколько хватает ширины; при смене карточки перекладываются заново |
| `⠿ Помнить порядок` | включено — раскладка сохраняется в браузере; снято — при следующей загрузке вернётся исходная |
| `↺ Исходный порядок` | сразу вернуть стандартную раскладку |

С клавиатуры: фокус на ручке `⠿`, затем `Ctrl`+`←`/`→` — другая колонка, `Ctrl`+`↑`/`↓` — сдвиг на 40 px.

Раскладка привязана к браузеру, а не к файлу: откроете другой трек — расположение останется вашим.

## Ограничения (честно)

- **Форматы** — только те, что декодирует браузер.
- **Дорожки** — DSP (Mid/Side + полосы), не нейросеть: разделение приблизительное.
- **Скорость** меняет темп и тон; pitch-preserving тайм-стретча нет. На скорости ≠ 1 полосы дорожек в прослушивании считаются уже после сдвига тона, а в экспорте — до; при уровнях 100 % это не слышно (сумма всё равно даёт исходник).
- **Запись с микрофона** синхронизируется по старту воспроизведения, задержка кодеков даёт смещение в десятки миллисекунд — дорожку можно подвинуть.
- **Запись исполнения** идёт в реальном времени: дубль длится столько, сколько играли; это не офлайн-рендер.
- **Память**: трек декодируется в RAM целиком (час стерео 44.1 кГц ≈ 1.2 ГБ); длинные экспорты занимают время.
- **Отмена** — для удаления участков, фиксации, дубля и возврата к исходнику (до трёх шагов вместе с настройками); правки полей и сэмплов отменить нельзя.
- **Автотюн** — гранулярный сдвиг: 452.3 Гц → 440.8 Гц при цели 440 (около 3 центов), но на вибрато и аккордах слышны артефакты.
- **Шумодав** рассчитан на фон с паузами; непрерывный тон он ослабляет вместе с шумом.
- **Голос** обрабатывает дорожку целиком, а не выделение.
- **Библиотека** — файлы в папке на диске; запись в папку требует Chrome/Edge и защищённого адреса (`localhost` или HTTPS).
- **Looperman** — лупы можно использовать в своих треках, но нельзя перераздавать «как есть»: файлы не коммитятся в репозиторий, а в библиотеке помечены как «только личное».
- **Android** — интерфейс адаптирован; микрофон работает на HTTPS-версии, из локального файла браузер его блокирует.
- При несохранённых фрагментах или сэмплах браузер спросит подтверждение при закрытии вкладки.

## Как устроено

- Один HTML: разметка, стили и два блока `<script>` — встроенный `lamejs` и код приложения (IIFE, без зависимостей).
- Вся обработка экспорта идёт через `renderRange(start, end, options)`: дорожки, тембр, сэмплы, фейды и скорость собираются в два `Float32Array` — MP3 и WAV кодируют именно их.
- Живое прослушивание: источник → мьют трека → потоковый процессор дорожек (движок экспорта) → громкость → полки тембра → мастер. Сэмплы играют отдельными голосами сразу в мастер — как в экспорте, мимо дорожек и тембра. Усиление ограничено по пику трека, поэтому поднятая громкость не даёт клиппинга. Штамп сборки виден в заголовке вкладки.
- Рендер включается только для того, что нельзя сделать нодами: фейды фрагмента. Соло-прослушивание дорожки идёт тем же графом: остальные три ветки просто глушатся, поэтому ползунки остаются мгновенными. Старт с середины трека читает исходный буфер с нужного сэмпла — без копирования.
- Автотюн: FFT-автокорреляция по кадрам, подтяжка к ноте гранулярным сдвигом с кроссфейдом.
- Шумодав: STFT, профиль шума по минимуму спектра, вычитание с ограничением ослабления.
- Запись исполнения: `MediaStreamAudioDestinationNode` + `MediaRecorder` пишут то, что уходит в выход.
- Волна на canvas, пики кэшируются по окну просмотра и ширине.
- Один `AudioContext` на всё приложение.

### Отладка

В консоли браузера: `window.audioSplitterDebug`

```js
audioSplitterDebug.state      // файл, фрагменты, сэмплы, выделение, скорость, уровни дорожек
audioSplitterDebug.audio      // играет ли, какой диапазон, с какой скоростью
audioSplitterDebug.select(2, 6)                  // выделить 2–6 с
audioSplitterDebug.analyze(2, 6, null, true, 1)  // RMS/пик рендера
audioSplitterDebug.buffer     // декодированный трек (AudioBuffer)
audioSplitterDebug.playerNodes // живой граф: pre, low, high, master, stems
```

## Проверка после правок

1. Загрузить трек — волна, длительность и частота на месте.
2. Выделить участок → «＋ Фрагмент» → экспорт MP3 и WAV.
3. Дорожка: `▶` (слышно только её), `⤓` — файл, размер WAV = `44 + секунды × частота × 4`.
4. Запись 2 с → дорожка появилась → «Сведение» → `▶` играет, `⤓ MP3` даёт файл.
5. Перетащить сэмпл по волне — позиция в карточке совпадает.
6. Скорость ×2 → длительность рендера вдвое меньше.
7. Поменять уровень дорожки или громкость во время игры — звук меняется без остановки.
8. «🗑 Удалить» → трек короче, `↶` возвращает и звук, и настройки.
9. «⏺ Зафиксировать» → сэмплы исчезли, дорожки по 100 %, трек звучит как микс.
10. «⏺ Записать исполнение» → 2 с игры → дубль в панели → «⇪ В трек» → трек стал дублем → «↺ Чистый трек» → вернулся исходник.
11. «Голос» → Автотюн 100 % → «Применить» → питч сдвинулся, `↶` возвращает.
12. Библиотека: «📂 Папка» → `library` → видны все файлы папки (118 CC0 + 39 локальных Looperman) → `＋` вставляет в трек.
13. Перетащить сэмпл из библиотеки на волну → встал в точку броска.
14. Перезагрузить → библиотека восстановилась.
15. `💾` пишет `manifest.json` обратно в папку.
16. `✎` → правим название/теги/папку/лицензию → сохраняется и попадает в фильтр папок.
17. `⤒` в строке сэмпла → файл в папке библиотеки (без папки — предупреждение).
18. Сортировка и её направление меняют порядок строк.
19. `☑` → две строки → папка/лицензия → «Применить (2)».
20. Консоль без ошибок.

## Что менялось

- **Сплиттер** — нарезка по равным частям и меткам, экспорт WAV.
- **Редактор** — волна с зумом, фрагменты с фейдами, MP3 через `lamejs`, дорожки Mid/Side, сэмплы, скорость.
- **Запись** — микрофон, дорожки поверх трека, перетаскивание сэмплов.
- **Монтаж** — удаление участков с отменой, фиксация обработки, прослушивание сэмплов поверх игры.
- **Сведение и исполнение** — микс в MP3/WAV, запись того, что слышно, возврат к чистому треку.
- **Голос** — шумодав, автотюн с ладом и тоникой, компрессор, нормализация.
- **Библиотека** — папка на диске с манифестом, лицензии, поиск, теги, папки, сортировка, массовые операции, 157 сэмплов.
