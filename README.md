# AudioSplitter

Одностраничный редактор аудио: нарезка трека на фрагменты, разделение на дорожки, запись с микрофона поверх трека, сэмплы и сведение в MP3/WAV.

Один файл `AudioSplitter.html`, без установки, сервера и интернета: открывается двойным щелчком в браузере, все вычисления идут локально, файлы никуда не отправляются. Кодировщик MP3 (`lamejs 1.2.1`, LGPL-3.0) встроен внутрь файла.

Репозиторий: <https://github.com/GitIT1979/Audiosplitter>

Версия для телефона (HTTPS): <https://gitit1979.github.io/Audiosplitter/> — нужна для записи с микрофона: браузер разрешает её только на защищённом адресе.

---

## Быстрый старт

1. Открыть `AudioSplitter.html`.
2. Перетащить трек в окно (или нажать «Открыть файл»).
3. Потянуть мышью по волне — получится выделение, нажать «+ Фрагмент из выделения».
4. В карточке фрагмента поправить начало/конец/длину/фейд/громкость либо подтянуть края прямо на волне.
5. Сохранить: «⤓» в карточке фрагмента, «⤓ MP3/WAV» в блоке «Сведение» — весь микс, или «⤓» в строке дорожки — отдельная дорожка.

## Возможности

### Волна и навигация
- Волна с линейкой времени и огибающей по каналам (широкое стерео не «схлопывается»).
- Зум ×1…×64: кнопки `−`/`+`, `Ctrl`+колесо (к курсору), двойной клик — вписать.
- Прокрутка: `Shift`+колесо или перетаскивание линейки; клик по линейке ставит курсор.
- Тянуть по волне — выделение; клик — курсор; тянуть край фрагмента — подрезка; тянуть плашку сэмпла — перемещение сэмпла.

### Фрагменты
- Создание из выделения, минимальная длина 0.05 с.
- **«✂ Cut»** — создаёт фрагмент из выделения и сразу сохраняет его файлом в выбранном формате.
- **«🗑 Удалить»** — убирает выделение из трека: остальное склеивается, фрагменты и сэмплы сдвигаются. Отменяется кнопкой «↶».
- Поля: начало, конец, длина, фейд (одинаковый на вход и выход), громкость в дБ.
- Правка краёв мышью на волне, дублирование, удаление, экспорт.
- Формат экспорта выбирается один на всё приложение: **MP3 192 кбит/с** или **WAV 16 бит**.
- Изменения фрагмента (поля, фейд, громкость, края) слышны сразу, если он играет.

### Дорожки (разделение на инструменты)
Четыре суммирующихся компонента; при уровнях 100 % их сумма совпадает с исходником (с точностью до округления float):

| Дорожка | Что выделяет | Метод |
|---|---|---|
| Вокал | центр, 150 Гц – 8 кГц | Mid-канал + полосовой фильтр |
| Инструментал | всё, кроме центра | исходник минус остальные полосы |
| Бас | ниже 140 Гц | low-pass 24 дБ/окт |
| Верх | выше 8 кГц | high-pass 24 дБ/окт |

- Уровень каждой дорожки 0–150 % — это микшер: «Вокал» в ноль даёт минусовку. Уровни слышны сразу, без остановки проигрывания.
- «Сброс» в шапке дорожек возвращает все уровни на 100 %.
- `▶` слушает только эту дорожку, `⤓` сохраняет её отдельным файлом.
- Разделение блочное (по 65 536 кадров, фильтры с состоянием), поэтому **ограничения по длине трека нет**: память зависит от размера результата, а не от промежуточных копий.

### Запись с микрофона
- Кнопка `🎤` в транспорте или «🎤 Записать» в блоке «Сэмплы»: играет трек, пишется микрофон.
- Запись включается после того, как трек реально зазвучал, — на длинном файле в начало не попадает пауза подготовки.
- По остановке запись декодируется и становится **отдельной дорожкой** на волне: её можно двигать, менять громкость, слушать и сохранять.
- Формат записи: `audio/webm;codecs=opus` → `audio/webm` → `audio/mp4` → `audio/ogg;codecs=opus` (что поддерживает браузер).
- Нужно разрешение на микрофон; при отказе показывается сообщение, приложение продолжает работать.
- На телефоне открывайте версию по HTTPS (<https://gitit1979.github.io/Audiosplitter/>): из локального файла браузер микрофон не даёт. Приложение само подсказывает это в блоке «Сэмплы».
- Запись идёт без эхо-подавления и АРУ (они портят музыку); если устройство не поддерживает такие настройки, включается обычный режим.
- Наденьте наушники: иначе микрофон запишет и трек из динамика.

### Сэмплы
- «＋ Добавить» — внешние звуки из файлов (можно несколько сразу); «🎤 Записать» — запись с микрофона.
- Каждый сэмпл получает позицию на таймлайне и громкость.
- На волне: пунктир старта, подсветка области и плашка с названием — за неё сэмпл перетаскивается.
- `▶` слушает сэмпл отдельно, а если трек играет — поверх него, не останавливая воспроизведение.
- `✂` удаляет выделенный участок из этой дорожки, `⤓` сохраняет её отдельным файлом.
- Сэмплы подмешиваются в прослушивание и в экспорт.

### Звук
- Громкость ±12 дБ, низ и верх (полки) ±12 дБ.
- Скорость 0.5–2.0 — применяется к тому, что слушаете или сохраняете (участок, фрагмент, целый трек). Это изменение темпа **вместе с тоном**, как ускорение плёнки; курсор при прослушивании движется синхронно.
- Все настройки применяются на слух: пока трек играет, звук пересобирается с текущей позиции (задержка около 0,2 с).

### Сведение
- `▶ Прослушать` — играет итог: трек + дорожки с уровнями + запись + сэмплы + скорость/тембр.
- `⤓ MP3` / `⤓ WAV` — сохраняет тот же итог в файл.
- `⏺ Зафиксировать` — впечатывает обработку (дорожки, тембр, скорость, сэмплы) в сам трек: дальше режете и сохраняете уже готовый звук.
- Если выделен фрагмент — сводится только он.
- Прослушивание и экспорт идут через один и тот же рендер, поэтому «слышу» и «сохранил» совпадают.

## Форматы

**Вход** — всё, что умеет декодировать браузер: MP3, WAV, OGG/Opus, FLAC, M4A/AAC, AIFF. Ограничение платформенное: например, Safari не читает FLAC через `decodeAudioData`, поддержка AAC зависит от ОС. При ошибке показывается сообщение, а не тишина.

**Выход** — MP3 192 кбит/с (CBR) и WAV 16 бит PCM, стерео, частота исходника (при неподдерживаемой MP3-частотe выполняется ресемплинг в 48 кГц).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Space` | играть / пауза |
| `Esc` | снять выделение |
| `Delete` / `Backspace` | удалить активный фрагмент |
| `←` / `→` | курсор на 1 с (`Shift` — на 5 с) |
| `+` / `−` | зум |
| `Ctrl`/`Cmd` + `D` | дублировать фрагмент |

Клавиши не срабатывают, пока фокус в поле ввода.

## Что и как сохраняется

| Что | Кнопка | Имя файла |
|---|---|---|
| Фрагмент | `⤓` в карточке | `<имя фрагмента>.mp3` / `.wav` (по умолчанию `clip_001`) |
| Дорожка | `⤓` в строке дорожки | `<файл>_vocal` / `_instrumental` / `_bass` / `_highs` |
| Запись или сэмпл | `⤓` в строке сэмпла | `<имя>.mp3` / `.wav` (`Запись 1`, имя файла сэмпла) |
| Сведение | `⤓ MP3` / `⤓ WAV` | `<файл>_mix.mp3` / `_mix.wav` |

Формат для кнопок фрагментов, дорожек и сэмплов берётся из списка «Формат» в шапке блока «Фрагменты».

## Ограничения (честно)

- **Форматы** — только те, что декодирует браузер; своего декодера в приложении нет.
- **Дорожки** — это DSP (Mid/Side + полосы), а не нейросеть. Разделение приблизительное; настоящее разделение инструментов требует Demucs/Spleeter на сервере.
- **Скорость** меняет и темп, и высоту тона (varispeed). Pitch-preserving тайм-стретча нет.
- **Запись** синхронизируется по старту воспроизведения; задержка микрофона и кодеков может дать смещение в десятки миллисекунд — при необходимости запись двигается по волне.
- **Память**: трек декодируется в RAM целиком (час стерео 44.1 кГц ≈ 1.2 ГБ). Длинные экспорты занимают время, MP3 кодируется с прогрессом.
- **Отмена** — есть только для удаления участков и фиксации (до трёх шагов вместе с настройками); правки полей и сэмплов отменить нельзя.
- **Android** — интерфейс адаптирован под телефон; запись с микрофона работает в версии по HTTPS (<https://gitit1979.github.io/Audiosplitter/>), из локального файла браузер микрофон блокирует.
- При несохранённых фрагментах или сэмплах браузер спросит подтверждение при закрытии вкладки.

## Как устроено

- Один HTML: разметка + стили + два блока `<script>` — сначала встроенный `lamejs`, затем код приложения (IIFE, без зависимостей).
- Вся обработка идёт через `renderRange(start, end, options)`: он собирает дорожки, тембр, сэмплы, фейды и скорость в два `Float32Array`. Прослушивание оборачивает результат в `AudioBuffer`, экспорт кодирует те же массивы — отсюда совпадение звука.
- Дорожки считаются блоками со stateful-биквадами, поэтому пиковая память не растёт с длиной.
- Волна рисуется на canvas; пики кэшируются по окну просмотра и ширине, поэтому перерисовка при проигрывании дешёвая.
- Один `AudioContext` на всё приложение (без утечки контекстов).

### Отладка

В консоли браузера доступен `window.audioSplitterDebug`:

```js
audioSplitterDebug.state      // файл, фрагменты, сэмплы, выделение, скорость, уровни дорожек
audioSplitterDebug.audio      // играет ли, какой диапазон, с какой скоростью
audioSplitterDebug.select(2, 6)          // выделить 2–6 с
audioSplitterDebug.analyze(2, 6, null, true, 1)  // RMS/пик рендера: (start, end, дорожки, сэмплы, скорость)
```

## Проверка после правок

Быстрый прогон, который ловит основные регрессии:

1. Загрузить трек — волна, длительность и частота на месте.
2. Выделить участок → «Фрагмент из выделения» → экспорт MP3 и WAV.
3. Дорожка: `▶` (слышно только её), `⤓` — файл сохраняется, размер = `44 + секунды × частота × 4` для WAV.
4. Запись 2 с → в списке появилась дорожка → «Сведение» → `▶` играет, `⤓ MP3` даёт файл.
5. Перетащить сэмпл по волне — позиция в карточке совпадает.
6. Скорость ×2 → длительность рендера вдвое меньше.
7. Поменять уровень дорожки или громкость во время игры — звук меняется без остановки.
8. «🗑 Удалить» выделение → трек короче, «↶» возвращает и звук, и настройки.
9. «⏺ Зафиксировать» → сэмплы исчезли, дорожки по 100 %, трек звучит как микс.
10. Консоль без ошибок.

## Что менялось

- **Сплиттер** — нарезка по равным частям и по меткам, экспорт WAV.
- **Редактор** — волна, зум, выделение, фрагменты с фейдами, MP3 через `lamejs`, дорожки Mid/Side, сэмплы, скорость.
- **Запись** — микрофон, дорожки поверх трека, перетаскивание сэмплов.
- **Без лимита** — блочное разделение на дорожки вместо ограничения в 4 минуты.
- **Сведение** — прослушивание и сохранение микса, экспорт отдельных дорожек.
- **Живой микс и Cut** — настройки меняются на слух, кнопка Cut сразу сохраняет выделенный фрагмент файлом, у дорожек появился сброс.
- **Монтаж** — удаление участков трека и дорожек с отменой, фиксация обработки в трек, прослушивание сэмплов поверх игры, адаптация под телефон.
- **Мобильная запись** — HTTPS-версия на GitHub Pages, подсказка про микрофон в интерфейсе, запись без обработки звука и напоминание про наушники.
