# AudioSplitter

Редактор аудио в одном HTML-файле: нарезка трека на фрагменты, разделение на дорожки, запись с микрофона поверх трека, сэмплы из библиотеки, обработка голоса и сведение в MP3/WAV.

Всё считается в браузере: файлы никуда не отправляются, сервер не нужен (кроме необязательного локального запуска, см. ниже). Кодировщик MP3 (`lamejs 1.2.1`, LGPL-3.0) встроен внутрь файла, поэтому приложение работает без интернета.

- Репозиторий: <https://github.com/GitIT1979/Audiosplitter>
- Версия по HTTPS (для телефона): <https://gitit1979.github.io/Audiosplitter/>

---

## Как запустить

**1. Просто открыть файл.** Двойной щелчок по `AudioSplitter.html`. Работает всё, кроме записи в папку библиотеки — на `file://` браузер её не разрешает.

**2. Локальный сервер (рекомендуется).** Двойной щелчок по `start-server.bat` (или `python serve.py` в папке проекта). Откроется <http://localhost:8000/AudioSplitter.html>. `localhost` считается защищённым адресом, поэтому здесь работают и доступ к папке библиотеки, и микрофон. Остановить — `Ctrl+C` в окне сервера.

**3. Телефон.** Открыть <https://gitit1979.github.io/Audiosplitter/>: без HTTPS браузер мобильного не даёт микрофон.

---

## Быстрый старт

1. Открыть приложение и загрузить трек.
2. Потянуть мышью по волне — получится выделение.
3. «＋ Фрагмент из выделения» — кусок станет фрагментом; «✂ Cut» — он ещё и сохранится файлом.
4. В карточке фрагмента поправить начало, конец, длину, фейд и громкость либо подтянуть края на волне.
5. «Сведение» → `▶ Прослушать` — услышать итог, `⤓ MP3` / `⤓ WAV` — записать его.

## Возможности

### Волна и навигация
- Волна с линейкой и огибающей по каналам — широкое стерео не «схлопывается» в ноль.
- Зум ×1…×64: кнопки `−`/`+`, `Ctrl`+колесо (к курсору), двойной клик — вписать.
- Прокрутка: `Shift`+колесо или перетаскивание линейки; клик по линейке ставит курсор.
- Тянуть по волне — выделение; клик — курсор; тянуть край фрагмента — подрезка; тянуть плашку сэмпла — перемещение.

### Фрагменты
- Минимальная длина 0.05 с, поля: начало, конец, длина, фейд, громкость в дБ.
- `✂ Cut` — создать фрагмент и сразу сохранить его файлом в выбранном формате.
- `🗑 Удалить` — вырезать выделение из трека: остальное склеивается, фрагменты и сэмплы сдвигаются. Отменяется кнопкой `↶`.
- Правка краёв мышью, дублирование, удаление, экспорт.
- Изменения фрагмента слышны сразу, если он играет.

### Дорожки (разделение на инструменты)
Четыре суммирующихся компонента; при уровнях 100 % их сумма совпадает с исходником (с точностью до округления float):

| Дорожка | Что выделяет | Метод |
|---|---|---|
| Вокал | центр, 150 Гц – 8 кГц | Mid-канал + полосовой фильтр |
| Инструментал | всё, кроме центра | исходник минус остальные полосы |
| Бас | ниже 140 Гц | low-pass 24 дБ/окт |
| Верх | выше 8 кГц | high-pass 24 дБ/окт |

- Уровень 0–150 % у каждой — это микшер: «Вокал» в ноль даёт минусовку. Меняется на слух, без остановки.
- «Сброс» возвращает все уровни на 100 %.
- `▶` слушает только дорожку, `⤓` сохраняет её файлом.
- Разделение блочное (65 536 кадров, фильтры с состоянием), поэтому **ограничения по длине трека нет**.

### Запись с микрофона
- `🎤` в транспорте или «🎤 Записать» в блоке «Сэмплы»: играет трек, пишется микрофон.
- Запись включается после того, как трек зазвучал, — в начало не попадает пауза подготовки.
- По остановке запись становится отдельной дорожкой на волне: двигается, регулируется, сохраняется.
- Форматы: `audio/webm;codecs=opus` → `audio/webm` → `audio/mp4` → `audio/ogg;codecs=opus`.
- Запрос идёт без эхо-подавления и АРУ (они портят музыку), с откатом на обычный режим.
- Нужно разрешение; при отказе показывается сообщение. Наденьте наушники — иначе микрофон запишет и трек из динамика.

### Сэмплы
- «＋ Добавить» — внешние звуки файлами, «🎤 Записать» — с микрофона.
- У каждого своя позиция на таймлайне и громкость.
- На волне: пунктир старта, подсветка области и плашка с названием — за неё сэмпл перетаскивается.
- `▶` слушает сэмпл отдельно, а поверх играющего трека — не останавливая воспроизведение.
- `✂` удаляет выделенный участок из этой дорожки, `⤓` сохраняет её файлом, `⤒` кладёт в библиотеку.

### Библиотека
- Папка `library/` на диске: `manifest.json`, звуковые файлы, `credits.txt`. **Папка — источник правды**, а не кеш браузера.
- «📂 Папка» — системный выбор папки с правом записи (Chrome/Edge): приложение читает файлы, а `💾` записывает `manifest.json` обратно.
- Папка запоминается: после перезагрузки доступ восстанавливается сам или кнопкой `🔓`.
- Где File System Access нет (Firefox, Safari, телефон) — «＋ Файлы»: ручной выбор, метаданные всё равно из манифеста.
- Поиск по названию, автору, тегу и лицензии; бейджи CC0 / CC BY / «только личное» / «своя запись».
- `▶` слушает, `＋` вставляет с позиции курсора, перетаскивание на волну ставит в точку броска.
- `✎` правит название, теги, папку и лицензию; при подключённой папке манифест перезаписывается сразу.
- `⤒` в строке сэмпла пишет его файлом в папку библиотеки и дописывает запись в манифест.
- Фильтр по папкам, чипы тегов, сортировка по имени / длине / дате / лицензии с направлением `↑`/`↓`.
- `☑` — массовые операции: папка и/или лицензия сразу для отмеченных.
- «credits» — список авторов и лицензий.
- В комплекте 100 CC0-сэмплов (54 категории: ударные, перкуссия, бас, синт, клавиши, струнные, духовые, вокал, FX, эмбиент) из Openverse.

### Голос
Обработка записи с микрофона или любого сэмпла:

- **Шумодав** — спектральное вычитание, профиль шума по тишине между фразами.
- **Автотюн** — подтяжка к ноте: хроматика или лад (мажор/минор) с тоникой; сила 0–100 %, скорость «мгновенно / быстро / обычно / плавно».
- **Обрезка низа** 80 Гц, **компрессор** 3:1, **нормализация** до −1 дБ.
- `▶ Послушать` — без изменения файла, `Применить` — заменить дорожку (отменяется `↶`).

### Звук
- Громкость ±12 дБ, полки низа и верха ±12 дБ.
- Скорость 0.5–2.0 — для участка, фрагмента или целого трека. Меняет темп **вместе с тоном** (как ускорение плёнки), курсор движется синхронно.
- Настройки применяются на слух: пока трек играет, звук пересобирается с текущей позиции (≈0,2 с).

### Сведение
- `▶ Прослушать` — итог: трек + дорожки + запись + сэмплы + скорость и тембр.
- `⤓ MP3` / `⤓ WAV` — тот же итог в файл; если выделен фрагмент, сводится только он.
- `⏺ Зафиксировать` — впечатать обработку в трек, дальше работать с готовым звуком.
- `⏺ Записать исполнение` — пишет то, что слышно, пока вы крутите ползунки и вставляете сэмплы. По остановке появляется **дубль**: послушать, сохранить или сделать треком.
- `↺ Чистый трек` — вернуть исходный файл и нейтральные настройки: не понравилось — нажали, трек снова чистый.
- Прослушивание и экспорт идут через один и тот же рендер, поэтому «слышу» и «сохранил» совпадают.

## Форматы

**Вход** — всё, что декодирует браузер: MP3, WAV, OGG/Opus, FLAC, M4A/AAC, AIFF. Ограничение платформенное: Safari не читает FLAC через `decodeAudioData`, поддержка AAC зависит от ОС. При ошибке — сообщение, а не тишина.

**Выход** — MP3 192 кбит/с (CBR) и WAV 16 бит PCM, стерео, частота исходника (неподдерживаемая MP3-частота ресемплится в 48 кГц).

| Клавиши | Действие |
|---|---|
| `Space` | играть / пауза |
| `Esc` | снять выделение |

## Что и как сохраняется

| Что | Кнопка | Имя файла |
|---|---|---|
| Фрагмент | `⤓` в карточке | `<имя фрагмента>.mp3` / `.wav` (по умолчанию `clip_001`) |
| Дорожка | `⤓` в строке дорожки | `<файл>_vocal` / `_instrumental` / `_bass` / `_highs` |
| Запись или сэмпл | `⤓` в строке | `<имя>.mp3` / `.wav` (`Запись 1`, имя файла сэмпла) |
| Сведение | `⤓ MP3` / `⤓ WAV` | `<файл>_mix.mp3` / `_mix.wav` |
| Дубль исполнения | `⤓` в панели дубля | `<файл>_take.mp3` / `.wav` |
| Своя запись в библиотеку | `⤒` в строке сэмпла | `<имя>.mp3` (или `.wav`) в папке `library/` |

Формат для кнопок фрагментов, дорожек и сэмплов берётся из списка «Формат» в шапке блока «Фрагменты».

## Ограничения (честно)

- **Форматы** — только те, что декодирует браузер.
- **Дорожки** — DSP (Mid/Side + полосы), не нейросеть: разделение приблизительное.
- **Скорость** меняет темп и тон; pitch-preserving тайм-стретча нет.
- **Запись с микрофона** синхронизируется по старту воспроизведения, задержка кодеков даёт смещение в десятки миллисекунд — дорожку можно подвинуть.
- **Запись исполнения** идёт в реальном времени: дубль длится столько, сколько играли; это не офлайн-рендер.
- **Память**: трек декодируется в RAM целиком (час стерео 44.1 кГц ≈ 1.2 ГБ); длинные экспорты занимают время.
- **Отмена** — для удаления участков, фиксации, дубля и возврата к исходнику (до трёх шагов вместе с настройками); правки полей и сэмплов отменить нельзя.
- **Автотюн** — гранулярный сдвиг: 452.3 Гц → 440.8 Гц при цели 440 (около 3 центов), но на вибрато и аккордах слышны артефакты.
- **Шумодав** рассчитан на фон с паузами; непрерывный тон он ослабляет вместе с шумом.
- **Голос** обрабатывает дорожку целиком, а не выделение.
- **Библиотека** — файлы в папке на диске; запись в папку требует Chrome/Edge и защищённого адреса (`localhost` или HTTPS).
- **Android** — интерфейс адаптирован; микрофон работает на HTTPS-версии, из локального файла браузер его блокирует.
- При несохранённых фрагментах или сэмплах браузер спросит подтверждение при закрытии вкладки.

## Как устроено

- Один HTML: разметка, стили и два блока `<script>` — встроенный `lamejs` и код приложения (IIFE, без зависимостей).
- Вся обработка идёт через `renderRange(start, end, options)`: дорожки, тембр, сэмплы, фейды и скорость собираются в два `Float32Array`. Прослушивание оборачивает их в `AudioBuffer`, экспорт кодирует те же массивы — отсюда совпадение звука.
- Дорожки считаются блоками со stateful-биквадами: пиковая память не растёт с длиной.
- Автотюн: FFT-автокорреляция по кадрам, подтяжка к ноте гранулярным сдвигом с кроссфейдом.
- Шумодав: STFT, профиль шума по минимуму спектра, вычитание с ограничением ослабления.
- Запись исполнения: `MediaStreamAudioDestinationNode` + `MediaRecorder` пишут то, что уходит в выход.
- Волна на canvas, пики кэшируются по окну просмотра и ширине.
- Один `AudioContext` на всё приложение.

### Отладка

В консоли браузера: `window.audioSplitterDebug`

```js
audioSplitterDebug.state      // файл, фрагменты, сэмплы, выделение, скорость, уровни дорожек
audioSplitterDebug.audio      // играет ли, какой диапазон, с какой скоростью
audioSplitterDebug.select(2, 6)                  // выделить 2–6 с
audioSplitterDebug.analyze(2, 6, null, true, 1)  // RMS/пик рендера
```

## Проверка после правок

1. Загрузить трек — волна, длительность и частота на месте.
2. Выделить участок → «＋ Фрагмент» → экспорт MP3 и WAV.
3. Дорожка: `▶` (слышно только её), `⤓` — файл, размер WAV = `44 + секунды × частота × 4`.
4. Запись 2 с → дорожка появилась → «Сведение» → `▶` играет, `⤓ MP3` даёт файл.
5. Перетащить сэмпл по волне — позиция в карточке совпадает.
6. Скорость ×2 → длительность рендера вдвое меньше.
7. Поменять уровень дорожки или громкость во время игры — звук меняется без остановки.
8. «🗑 Удалить» → трек короче, `↶` возвращает и звук, и настройки.
9. «⏺ Зафиксировать» → сэмплы исчезли, дорожки по 100 %, трек звучит как микс.
10. «⏺ Записать исполнение» → 2 с игры → дубль в панели → «⇪ В трек» → трек стал дублем → «↺ Чистый трек» → вернулся исходник.
11. «Голос» → Автотюн 100 % → «Применить» → питч сдвинулся, `↶` возвращает.
12. Библиотека: «📂 Папка» → `library` → видны 100 сэмплов → `＋` вставляет в трек.
13. Перетащить сэмпл из библиотеки на волну → встал в точку броска.
14. Перезагрузить → библиотека восстановилась.
15. `💾` пишет `manifest.json` обратно в папку.
16. `✎` → правим название/теги/папку/лицензию → сохраняется и попадает в фильтр папок.
17. `⤒` в строке сэмпла → файл в папке библиотеки (без папки — предупреждение).
18. Сортировка и её направление меняют порядок строк.
19. `☑` → две строки → папка/лицензия → «Применить (2)».
20. Консоль без ошибок.

## Что менялось

- **Сплиттер** — нарезка по равным частям и меткам, экспорт WAV.
- **Редактор** — волна с зумом, фрагменты с фейдами, MP3 через `lamejs`, дорожки Mid/Side, сэмплы, скорость.
- **Запись** — микрофон, дорожки поверх трека, перетаскивание сэмплов.
- **Монтаж** — удаление участков с отменой, фиксация обработки, прослушивание сэмплов поверх игры.
- **Сведение и исполнение** — микс в MP3/WAV, запись того, что слышно, возврат к чистому треку.
- **Голос** — шумодав, автотюн с ладом и тоникой, компрессор, нормализация.
- **Библиотека** — папка на диске с манифестом, лицензии, поиск, теги, папки, сортировка, массовые операции, 100 CC0-сэмплов.
- **Платформы** — адаптив под телефон, HTTPS-версия для микрофона, локальный сервер для доступа к папке.
